# Twitch Scraper

> 🇬🇧 [English version of README](README.md) | 📘 [Техническая документация](https://github.com/MacroVoid/TwitchScraper/wiki)

Расширение для браузера (Manifest V3), позволяющее собирать данные о прямых трансляциях с любой категории на Twitch.tv и экспортировать их в формате JSON или Markdown.

## Возможности

- Сбор данных из любой категории Twitch с автоматической обработкой пагинации
- Экспорт не только базовых параметров (название, зрители), но и расширенных: ссылки на соцсети, панели канала (правила, Discord, описание), время начала и продолжительность стрима
- Вывод в JSON для программной обработки или в Markdown для удобного чтения
- Гибкая настройка формата времени: ISO 8601, Unix Timestamp, GMT, локальное время (12/24ч), HH:MM:SS или секунды
- Интерфейс на русском и английском языках

## Использование

1. Установите расширение в Chromium-браузер (Chrome, Edge, Brave)
2. Перейдите на страницу любой категории Twitch, например `twitch.tv/directory/category/minecraft`
3. Откройте Twitch Scraper через иконку в панели браузера
4. Выберите нужные поля данных и нажмите **Собрать**
5. Дождитесь завершения сбора или нажмите **Завершить досрочно**, чтобы скачать уже собранные данные

## Установка из исходного кода

1. Склонируйте или скачайте репозиторий
2. Откройте `chrome://extensions/`
3. Включите **Режим разработчика** в правом верхнем углу
4. Нажмите **Загрузить распакованное** и укажите папку с расширением
