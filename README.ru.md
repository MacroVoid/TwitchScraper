# Twitch Scraper

> 🇬🇧 [English version of README](README.md) | 📘 [Техническая документация](https://github.com/MacroVoid/TwitchScraper/wiki)

**Twitch Scraper** — это мощное и легковесное браузерное расширение (Manifest V3), которое позволяет легко извлекать данные о прямых трансляциях из любой категории на Twitch.tv и экспортировать их в структурированные файлы JSON или красивые Markdown документы.

![Twitch Scraper Preview](https://lucide.dev/logo.svg) <!-- Замените на реальный скриншот расширения -->

## ✨ Возможности

- **Экспорт в один клик**: Быстро собирайте тысячи трансляций из любой игры или категории Twitch.
- **Обход лимитов**: Расширение автоматически обрабатывает пагинацию Twitch и безопасно собирает данные, используя вашу активную сессию.
- **Глубокий сбор данных**: Собирайте не только названия стримов и количество зрителей, но и расширенную информацию, такую как ссылки на социальные сети стримеров и текст из информационных панелей (правила, Discord, описание канала).
- **Выбор формата**: Экспортируйте чисто отформатированные JSON-файлы для использования в коде или удобные для чтения Markdown-файлы.
- **Мультиязычность**: Интерфейс расширения "из коробки" поддерживает русский и английский языки.

## 🚀 Как использовать

1. **Установите** расширение в ваш браузер на базе Chromium (Chrome, Edge, Brave).
2. **Откройте** любую страницу категории Twitch (например, `twitch.tv/directory/category/minecraft`).
3. Нажмите на иконку **Twitch Scraper** на панели расширений браузера.
4. Выберите поля данных, которые хотите собрать, и нажмите кнопку **Собрать**.
5. Дождитесь окончания процесса или нажмите **Завершить досрочно**, чтобы прервать сбор и скачать то, что уже найдено.

## ⚙️ Установка (Режим разработчика)

1. Скачайте этот репозиторий на свой компьютер.
2. Откройте браузер и перейдите на страницу `chrome://extensions/`.
3. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите папку проекта.
5. Расширение установлено и готово к работе!
